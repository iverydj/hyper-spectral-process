## `hyper_spectral_process.io.spectrum_map`

The :class:`StandardSpectrumMap` container and its NPZ file format.

- **class `StandardSpectrumMap(spectra: np.ndarray, xy: np.ndarray, axis: np.ndarray, unit: str = '') -> None`**: ``N`` spectra on a common, strictly increasing spectral axis.
    - `n_spectra`: Number of spectra ``N``.
    - `n_points`: Number of axis samples ``M``.
    - `replace(self, **changes) -> StandardSpectrumMap`: Copy with some fields replaced, e.g. ``ssm.replace(spectra=new)``.
    - `select(self, rows) -> StandardSpectrumMap`: Subset of spectra by boolean mask ``(N,)`` or integer indices.
    - `from_unsorted(cls, spectra, xy, axis, unit: str = '') -> StandardSpectrumMap`: Build a map from an axis in any order.
    - `save(self, path: str | Path, *, compressed: bool = True) -> None`: Write the map as NPZ with keys ``spectra``, ``xy``, ``axis``, ``unit``.
    - `load(cls, path: str | Path) -> StandardSpectrumMap`: Read an NPZ written by :meth:`save` (the ``unit`` key is optional).
- `raster_indices(xy: np.ndarray, decimals: int = 6) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]`: Locate every spectrum on the raster spanned by its coordinates.
- `to_image(values: np.ndarray, xy: np.ndarray, decimals: int = 6) -> tuple[np.ndarray, np.ndarray, np.ndarray]`: Arrange per-spectrum ``values`` ``(N,)`` on the raster of ``xy``.

## `hyper_spectral_process.io.axis`

Conversions between wavelength, photon energy and Raman shift axes.

- `energy_constant(unit: str) -> float`: ``K`` in ``E = K / lambda[nm]`` for ``unit`` ``"eV"`` or ``"cm^-1"``.
- `wavelength_jacobian(wavelength_nm: np.ndarray, unit: str, reference_nm: Optional[float] = None) -> np.ndarray`: ``|d lambda / d E| = lambda**2 / K`` on a wavelength grid.

- `raman_shift_to_wavelength(ssm: StandardSpectrumMap, laser_nm: float, *, jacobian: bool) -> StandardSpectrumMap`: Convert a Raman-shift map (``"cm^-1"``) to absolute wavelength in nm.
- `wavelength_to_raman_shift(ssm: StandardSpectrumMap, laser_nm: float, *, jacobian: bool) -> StandardSpectrumMap`: Convert a wavelength map to Raman shift ``1e7 / laser_nm - 1e7 / lambda`` in cm^-1.

## `hyper_spectral_process.preprocess.runner`

- **class `InputFile(path: Path, source_id: str, class_name: str, metadata: Mapping[str, str] = <factory>) -> None`**: One input map: a StandardSpectrumMap NPZ, its unique ``source_id`` and its class.

## `hyper_spectral_process.preprocess.despike`

Despike stage: remove cosmic-ray spikes.

- `despike_simple(ssm: StandardSpectrumMap, threshold: float) -> StandardSpectrumMap`: Replace jumps larger than ``threshold`` (data units) by linear interpolation.
- `whitaker_hayes_mask(spectra: np.ndarray, threshold: float = 7.0, max_width: Optional[int] = 2) -> np.ndarray`: Spike mask ``(N, M)`` from the Whitaker-Hayes test.
- `despike_whitaker_hayes(ssm: StandardSpectrumMap, threshold: float = 7.0, m: int = 3, *, max_width: Optional[int] = 2, protect: Sequence[tuple[float, float]] = ()) -> StandardSpectrumMap`: Whitaker-Hayes despiking.
- `residual_reference(ssm: StandardSpectrumMap, window: int = 9, polyorder: int = 3) -> np.ndarray`: Savitzky-Golay reference curve ``(N, M)`` of the residual despike pass.
- `despike_residual(ssm: StandardSpectrumMap, ref_window: int = 9, ref_polyorder: int = 3, threshold: float = 6.0, m: int = 2, replace: str = 'ref', protect: Sequence[tuple[float, float]] = ()) -> StandardSpectrumMap`: Residual z-score despiking.
- `despike_two_pass(ssm: StandardSpectrumMap, *, wh_threshold: float = 7.0, wh_m: int = 3, wh_max_width: Optional[int] = 2, ref_window: int = 9, ref_polyorder: int = 3, resid_threshold: float = 6.0, resid_m: int = 2, resid_replace: str = 'ref', protect: Sequence[tuple[float, float]] = ()) -> tuple[StandardSpectrumMap, StandardSpectrumMap, np.ndarray]`: Whitaker-Hayes pass followed by the residual pass.

## `hyper_spectral_process.preprocess.baseline`

Baseline stage: estimate a smooth background and subtract it.

- `minline_baseline(x: np.ndarray, y: np.ndarray, window: int, step: int) -> np.ndarray`: Baseline through the minima of the windows ``[s, s + window)``, ``s = 0, step, 2 step, ...``.
- `protect_mask(axis: np.ndarray, peak_positions: Sequence[float], half_width: float) -> np.ndarray`: Samples within ``half_width`` (axis units) of any of ``peak_positions``.
- `fill_masked(y: np.ndarray, mask: np.ndarray) -> np.ndarray`: Replace ``y[mask]`` by linear interpolation (in sample index) from the nearest unmasked samples.
- `strip_windows(window_min: int, window_max: int) -> list[int]`: Window lengths ``window_min, window_min + 2, ...`` up to ``window_max``, each made odd.
- `peakstrip_baseline(y: np.ndarray, window_min: int, window_max: int, polyorder: int = 0, protect: Optional[np.ndarray] = None) -> np.ndarray`: Iterative peak stripping.
- `anchor_baseline(spectra: np.ndarray, axis: np.ndarray, anchors: Sequence[tuple[float, float]], degree: Optional[int] = 1, reference: Optional[np.ndarray] = None) -> np.ndarray`: Least-squares background ``(N, M)`` through the samples inside the ``anchors`` ranges.
- `subtract_baseline(ssm: StandardSpectrumMap, mode: str, *, minline_window: int = 500, minline_step: int = 150, ps_window_min: int = 31, ps_window_max: int = 151, ps_polyorder: int = 0, protect_peaks: Optional[Sequence[float]] = None, protect_half_width: float = 15.0, anchors: Sequence[tuple[float, float]] = (), anchor_degree: Optional[int] = 1, anchor_reference: Optional[np.ndarray] = None, clip_negative: bool = False) -> tuple[StandardSpectrumMap, np.ndarray]`: Estimate and subtract a baseline; returns ``(corrected map, baseline (N, M))``.

## `hyper_spectral_process.fit.lineshapes`

Unit-height peak profiles and their analytic area and FWHM.

- `gaussian(x, pos, fwhm)`: Unit-height Gaussian of FWHM ``fwhm``.
- `lorentzian(x, pos, fwhm)`: Unit-height Lorentzian of FWHM ``fwhm``.
- `pseudo_voigt(x, pos, fwhm, eta)`: Fixed-eta pseudo-Voigt ``eta L + (1 - eta) G`` with one shared FWHM.
- `tch_fwhm_eta(width_g, width_l)`: Profile FWHM and mixing ``eta`` (clipped to [0, 1]) of the TCH pseudo-Voigt.
- `tch_height_fraction(eta)`: Lorentzian fraction of the peak height for the area fraction ``eta`` (same FWHM).
- `pseudo_voigt_tch(x, pos, width_l, width_g)`: Unit-height TCH pseudo-Voigt from the Lorentzian FWHM ``width_l`` and the Gaussian FWHM ``width_g``.
- `fano(x, pos, width, q)`: Unit-height Breit-Wigner-Fano profile with resonance FWHM ``width`` and asymmetry ``q``.
- `peak_area(peak_type: str, height, width, eta=None, width_g=None)`: Analytic integral of ``height * profile`` over the whole axis (NumPy).
- `peak_fwhm(peak_type: str, width, width_g=None, q=None)`: FWHM of the profile (NumPy).

## `hyper_spectral_process.fit.objective`

The fit objective: weighted mean squared residual plus the soft spring prior.

- `spring(value: torch.Tensor, anchor: torch.Tensor, limit: torch.Tensor, reg: torch.Tensor) -> torch.Tensor`: ``reg * (d^2 + relu(|d| - 1))`` with ``d = (value - anchor) / limit`` (elementwise).
- `data_term(recon: torch.Tensor, y: torch.Tensor, w: torch.Tensor) -> torch.Tensor`: Weighted mean squared residual of every spectrum ``(B,)``; ``w`` has shape ``(1, L)``.
- `prior_term(params: dict, anchors: dict, limits: dict, regs: dict, height_sign_reg: float) -> torch.Tensor`: Spring prior and negative-height penalty of every spectrum ``(B,)``.
